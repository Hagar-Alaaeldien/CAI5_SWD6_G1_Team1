# Test Documentation

This directory contains the testing documentation for the SauceDemo application.

### Test Cases
Contains the functional test cases covering:
- Login and authentication
- Product inventory
- Shopping cart
- Navigation menu
- Positive, negative, and edge-case scenarios

### Bug Reports
Contains documented defects identified during manual testing, including:
- Defect descriptions and reproduction steps
- Expected vs. actual results
- Severity and priority
- Related test case IDs
- Evidence references
